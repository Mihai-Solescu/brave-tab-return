# Privacy policy for Tab Detach & Return

Tab Detach & Return does not collect or transmit personal data. It has no analytics, advertising, accounts, or external servers.

## Local storage

The extension temporarily stores tab IDs, original window IDs, tab positions, and saved pinned state in the browser's session storage. It uses these records solely to return detached tabs to their original windows and positions.

This information stays on your device and is not synced to other devices. Records are removed when tabs are returned through the extension or closed. Session storage is cleared when the browser restarts or the extension is disabled, reloaded, or uninstalled.

## Browser access

The extension uses browser tab and window APIs to move tabs and respond to detach and attach events. It does not read or store page contents, page addresses, browsing history, passwords, or personal communications. It responds to configured shortcut commands without recording your typing.

## Sharing

The extension does not sell or transfer data to third parties.

## Contact

For questions about this policy, open an issue in the GitHub repository hosting this file. Please do not include private information in public issues.
